This is the official website for Vegas Freedom Dance Studio, built with React and Vite.
The purpose of this project is to provide a clear, modern, and user-friendly experience for all visitors.

🚀 Main Goals for Update

Modernize the design: Use a clean, professional, and visually appealing layout.
Improve clarity: Make all information easy to find and understand.
Mobile-friendly: Ensure the site looks and works great on all devices.
Fast performance: Optimize for quick loading and smooth interactions.
Easy maintenance: Write clean, organized, and well-documented code.

📋 What to Update

1. Project Setup

Refactor codebase using React with Vite for faster development.
Organize folders: /components, /pages, /assets, /styles, etc.

2. Content & Structure

Homepage: Clear headline, subheadline, and main call-to-action (CTA).
Navigation: Simple, intuitive menu with links to key sections (Home, About, Classes, Schedule, Contact).
About Page: Studio story, mission, team bios.
Classes Page: List and describe all class types, levels, and age groups.
Schedule Page: Display or link to up-to-date class schedule.
Pricing: Clearly show class prices and packages (if available).
Testimonials: Add reviews from students/parents.
Contact Page: Easy contact form, studio address, phone, email, and map.
Footer: Social media links, copyright.

3. Design & UX

Use a modern color palette and typography.
Add high-quality, relevant images (studio, classes, instructors, etc.).
Ensure all sections are visually separated and readable.
Responsive design for mobile, tablet, and desktop.

4. Technical Improvements

Use React functional components and hooks.
Modular CSS (CSS Modules, Tailwind CSS, or styled-components).
Optimize all images and assets for fast loading.
Set up SEO basics: meta titles, descriptions, and alt text for images.
Accessibility: good contrast, semantic HTML, keyboard navigation.

5. Extra Features (optional)

Blog or news section for updates and announcements.
Online registration or booking for classes.
FAQ section for common questions.

🛠️ How to Run Locally

# Clone the repo

git clone https://github.com/yourusername/vegasfreedomdancestudio.git

# Go into the project directory

cd vegasfreedomdancestudio

# Install dependencies

npm install

# Start the development server

npm run dev
